# Konvert

Private, in-browser file converter. **Phase 1: PDF → JPG** (300 DPI default, up to 1200, quality up to 100, multi-page PDFs download as a ZIP).

Everything runs locally with [PDF.js](https://mozilla.github.io/pdf.js/) and [fflate](https://github.com/101arrowz/fflate). Files are never uploaded.

## Deploy on GitHub Pages
1. Push `index.html` and `.nojekyll` to the root of a repo.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. Open `https://<username>.github.io/<repo>/`.
